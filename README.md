# 🎲 Игра «Угадай число»

Моя первая игра на Python! Компьютер загадывает число от 1 до 100, а вы пытаетесь его угадать.

## 🚀 Как играть
1. Запустите файл `guess_the_number.py`
2. Вводите числа от 1 до 100
3. Следуйте подсказкам
4. Победа — когда угадаете число

## 🛠️ Что использовано
- Python 3.12
- Модуль `random`
- Функции, циклы, условия
